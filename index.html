MULTI-USER CLOUD SYNC

Cloud Database Setup (GitHub Pages / Firebase)

Connect a free Google Firebase Firestore database so multiple team members on different laptops and mobile phones see real-time updates when hosted on GitHub Pages.

How to get free Firebase Config (Takes 1 minute):
  1. Go to Firebase Console and create a free project.
  2. Click Firestore Database > Create database (Start in test mode).
  3. Click Project Settings (gear icon) > Add Web App (</>) > Copy the firebaseConfig JSON.
Status: Standalone / Local Database
